3:Td9c,<h2>Overview</h2>
<p>I design agent systems as controlled workflows rather than unconstrained chains of model calls. The agent can interpret context, propose a plan, and coordinate tools, but consequential transitions remain observable and subject to explicit human approval.</p>
<p>Two implementations shaped this approach: an MCP-integrated evaluation workflow built during my Adobe internship and BrandForge, a production-style multi-agent platform with durable approval checkpoints.</p>
<blockquote>
<p>Agents propose and coordinate. Tools execute through defined interfaces. People retain authority at the decisions that matter.</p>
</blockquote>
<h2>MCP-integrated evaluation at Adobe</h2>
<p>I built a LangGraph agent that connected to Adobe PDF Spaces through Model Context Protocol. The workflow generated an evaluation plan, paused for human review before execution, and recorded agent activity with LangSmith tracing.</p>
<h3>Selected results</h3>
<ul>
<li>Reduced an end-to-end evaluation feedback cycle from 48 hours to 30 minutes.</li>
<li>Used MCP as a clear boundary between agent reasoning and document capabilities.</li>
<li>Required human approval before a generated plan could execute.</li>
<li>Traced the workflow so plans, tool activity, and outcomes could be inspected during review.</li>
<li>Paired the workflow with a LiteLLM-based LLM-as-Judge harness whose rubric refinement with domain reviewers raised F1 on a labeled evaluation set from 0.79 to 0.92.</li>
</ul>
<h2>BrandForge multi-agent platform</h2>
<p>BrandForge applies the same control principles to a larger creative workflow. A deterministic state machine coordinates brand compilation, planning, eight-way generation, ranking, and four versioned approval gates.</p>
<h3>Selected results</h3>
<ul>
<li>Built idempotent FastAPI endpoints with tenant isolation and optimistic concurrency so retries and simultaneous reviews could not silently corrupt workflow state.</li>
<li>Implemented a two-stage multimodal ranker with policy, claims, and accessibility critics; Bradley-Terry preference scoring; MMR diversity; and vision-based alignment scores.</li>
<li>Added OpenTelemetry traces with Tempo and Grafana for end-to-end observability.</li>
<li>Built a tenant-isolated PostgreSQL and pgvector retrieval layer with row-level security, policy filters, idempotent indexing, and a bounded SQLite fallback.</li>
<li>Benchmarked on a 120-scenario deterministic evaluation with ablations: multi-agent generation alone gave no gain over a single output (61.7% task success, 17.5% brand-claim violations at 8x the API calls), while adding two-stage reranking raised task success to 100% and cut claim violations to 0% at the same 16 calls.</li>
<li>Verified workflow behavior with 90 automated tests.</li>
</ul>
<h2>Design principles</h2>
<ul>
<li><strong>Explicit state:</strong> every transition is represented in a deterministic workflow rather than hidden inside a prompt loop.</li>
<li><strong>Bounded tools:</strong> MCP or typed service interfaces separate reasoning from side effects.</li>
<li><strong>Human authority:</strong> approval gates protect high-impact transitions without forcing people to perform repetitive orchestration.</li>
<li><strong>Idempotency and concurrency control:</strong> safe retries and version checks make long-running workflows reliable.</li>
<li><strong>Traceability:</strong> plans, tool calls, approvals, and outputs remain inspectable after execution.</li>
